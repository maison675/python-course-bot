# Операторы и арифметика — от 0 до 100%

Операторы — это символы, которые выполняют действия над значениями. `+`, `-`, `*`, `/` — арифметика. `==`, `<`, `>` — сравнения. `and`, `or`, `not` — логика. `&`, `|`, `^` — побитовые. И ещё с десяток специализированных.

Кажется банальным: «5 + 3 = 8, что тут разбирать». Но в Python за каждым оператором стоит вызов **dunder-метода** (`__add__`, `__lt__`, `__and__`), и поведение оператора полностью определяется типами операндов. Поэтому `+` для строк — конкатенация, для списков — расширение, для чисел — сложение. Это полиморфизм через операторы — мощная штука, и мы её разберём.

---

## 1. Арифметические операторы

| Оператор | Что делает | Пример |
|---|---|---|
| `+` | сложение | `2 + 3 = 5` |
| `-` | вычитание | `10 - 3 = 7` |
| `*` | умножение | `4 * 5 = 20` |
| `/` | деление (всегда float) | `10 / 3 = 3.333...` |
| `//` | целочисленное деление | `10 // 3 = 3` |
| `%` | остаток от деления | `10 % 3 = 1` |
| `**` | возведение в степень | `2 ** 10 = 1024` |
| унарный `-` | смена знака | `-x` |
| унарный `+` | плюс (для int — ничего, но может быть переопределён) | `+x` |

### Критическое отличие `/` и `//`

```python
10 / 3      # 3.3333333333333335 — float
10 // 3     # 3                  — int
10.0 // 3   # 3.0                — float, но округлённый
-7 // 2     # -4 — а не -3! Округление в сторону минус бесконечности
-7 / 2      # -3.5
```

`//` называется «floor division» — округление **вниз** (к минус бесконечности), а не к нулю. Поэтому для отрицательных чисел результат может удивить.

В Python 2 `/` для int делал floor division — то же что `//`. С Python 3 `/` всегда float. Если ты видишь в старом коде `from __future__ import division` — это попытка получить Python 3 поведение в Python 2.

### `%` — остаток

```python
10 % 3      # 1
-7 % 3      # 2 — а не -1! Знак результата совпадает со знаком делителя
7 % -3      # -2

# Полезные применения:
n % 2       # 0 если чётное, 1 если нечётное
n % 10      # последняя цифра
hours = total_minutes // 60
mins = total_minutes % 60
```

Связь `//` и `%` подчиняется тождеству:
```python
(a // b) * b + (a % b) == a
```

Всегда выполняется. Это и есть математическое определение.

### `**` — степень

```python
2 ** 10       # 1024
2 ** 0.5      # 1.4142135623730951 — sqrt(2)
2 ** -1       # 0.5
(-1) ** 0.5   # (6.123233995736766e-17+1j) — комплексное!
```

В отличие от других операторов, `**` право-ассоциативен:
```python
2 ** 3 ** 2   # 2 ** (3 ** 2) = 2 ** 9 = 512, а НЕ (2**3)**2 = 64
```

Для модульного возведения в степень есть встроенная функция `pow(a, b, mod)`:
```python
pow(2, 100, 1000)   # 2^100 mod 1000 = 376
```

Эта форма гораздо быстрее `(2**100) % 1000`, потому что не строит огромное промежуточное число. Используется в криптографии (RSA), хешах.

## 2. Приоритет операторов

Чем выше — тем раньше выполняется. Операторы одного уровня — слева направо (кроме `**`).

```
1.  (...)             — скобки
2.  x[i], x.attr      — индексация и атрибуты
3.  await x           — async
4.  **                — степень (право-ассоциативен)
5.  +x, -x, ~x        — унарные
6.  *, /, //, %, @    — умножение/деление
7.  +, -              — сложение/вычитание
8.  <<, >>            — битовые сдвиги
9.  &                 — битовый AND
10. ^                 — битовый XOR
11. |                 — битовый OR
12. ==, !=, <, >, <=, >=, is, is not, in, not in   — сравнения
13. not               — логическое НЕ
14. and               — логическое И
15. or                — логическое ИЛИ
16. if-else (тернарный)
17. lambda
18. := (walrus)
```

**Не учи наизусть**. Когда сомневаешься — ставь скобки. Они бесплатные и делают код понятнее.

```python
# Без скобок:
x = 2 + 3 * 4 ** 2 - 1     # = 2 + 3*16 - 1 = 49

# Со скобками — то же самое, но яснее:
x = 2 + (3 * (4 ** 2)) - 1
```

## 3. Сравнения

```python
5 == 5            # True
5 != 6            # True
5 < 6             # True
5 <= 5            # True
"a" < "b"         # True — лексикографически
[1, 2] < [1, 3]   # True — поэлементно
```

### Цепочки сравнений

В Python можно писать:
```python
1 < x < 10        # эквивалентно: (1 < x) and (x < 10)
0 <= i < len(lst) # стандартная проверка границ
a == b == c       # все три равны
1 < 2 < 3 < 4     # цепочка любой длины
```

Это **отличается** от большинства других языков (C, Java), где `1 < x < 10` сначала вычислил бы `1 < x` → True/False (1 или 0), а потом сравнил с 10.

Подвох:
```python
False == False == True   # False! Эквивалентно (False == False) and (False == True)
                         # = True and False = False
```

### `is` / `is not`

Сравнение **по идентичности**, не значению. Подробно — в теме «Переменные».

```python
x is None         # ✅ правильно
x == None         # ⚠️ работает, но плохой стиль
x is not None     # ✅
not (x is None)   # ❌ плохо читается
```

### `in` / `not in`

Проверка вхождения:
```python
3 in [1, 2, 3]            # True
"a" in "abc"              # True — подстрока
"key" in {"key": 1}       # True — для dict проверяет КЛЮЧИ, не значения
1 in {"a": 1, "b": 2}     # False — это значение, а не ключ
```

Сложность зависит от типа:
- list, tuple, str: O(n) — линейный поиск
- dict, set, frozenset: O(1) — хеш-таблица

Поэтому если делаешь много проверок «это в наборе» — заведи `set`, не list.

## 4. Логические операторы

```python
True and False       # False
True or False        # True
not True             # False
```

### Короткое замыкание (short-circuit)

`and` и `or` **не вычисляют** правый операнд, если результат уже понятен:

```python
False and divide_by_zero()    # False — divide_by_zero() не вызывается
True or expensive_call()       # True — expensive_call() пропускается
```

Это используется как **защита**:
```python
if x is not None and x.value > 0:
    ...
# если бы and вычислялся всегда — упало бы на x.value при x=None
```

И как **значение по умолчанию**:
```python
name = user_input or "Anonymous"   # если пустая строка — то "Anonymous"
```

### `and` / `or` возвращают **операнд**, не True/False

```python
"a" or "b"      # 'a' — первый truthy
""  or "b"      # 'b' — первый был falsy, возвращён следующий
"a" and "b"     # 'b' — оба truthy, возвращён последний
""  and "b"     # '' — первый falsy, дальше не идём

3 or 5          # 3
0 or 5          # 5
None or "default"   # 'default'
```

Это позволяет компактные конструкции:
```python
items = data.get("items") or []
config = user_config or default_config
```

Но в булевом контексте (`if`, `while`) преобразуется в True/False:
```python
if "a" or "":   # эквивалентно if "a": — truthy
    ...
```

### Истинность объектов (truthiness)

В Python в булевом контексте каждый объект превращается в True или False по правилам:

**Falsy:**
- `False`, `None`
- Числа: `0`, `0.0`, `0j`
- Пустые контейнеры: `""`, `[]`, `{}`, `set()`, `()`
- Кастомные объекты с `__bool__()` → False, или `__len__()` → 0

**Всё остальное — Truthy.**

```python
if data:           # True если data непустой/ненулевой
    process(data)

if not data:       # True если data пуст или None
    return
```

Использование truthiness — хороший Pythonic стиль вместо `if len(data) > 0`.

## 5. Побитовые операторы

Работают над целыми числами, оперируя их **двоичным представлением**.

| Оператор | Что делает |
|---|---|
| `&` | побитовое И (AND) |
| `|` | побитовое ИЛИ (OR) |
| `^` | побитовое исключающее ИЛИ (XOR) |
| `~` | побитовая инверсия (NOT) |
| `<<` | сдвиг влево |
| `>>` | сдвиг вправо |

```python
0b1010 & 0b1100   # 0b1000 = 8
0b1010 | 0b1100   # 0b1110 = 14
0b1010 ^ 0b1100   # 0b0110 = 6
~5                # -6 — инверсия в two's complement: ~x == -(x+1)
1 << 4            # 16 — 1 со сдвигом на 4 позиции = 2^4
16 >> 2           # 4 — 16 / 2^2

# Проверка/установка/сброс битов
flags = 0b101
flags |= 0b010    # установить бит 2: 0b111 = 7
flags & 0b010     # проверка бита 2: 0b010 (truthy)
flags &= ~0b010   # сбросить бит 2: 0b101 = 5
```

Используется в:
- работе с флагами (например, режимы файлов: `O_RDWR | O_CREAT`);
- криптографии и хешах (`xor` для шифрования);
- работе с регистрами устройств;
- оптимизациях (умножение/деление на степень двойки через сдвиг).

`set` тоже использует `&`, `|`, `^`, `-` — но там это операции над множествами, не побитовые.

## 6. Операторы присваивания

Базовый — `=`. Расширенные комбинируют операцию и присваивание:

```python
x = 5
x += 3      # x = x + 3, теперь x = 8
x -= 2      # 6
x *= 2      # 12
x /= 4      # 3.0
x //= 2     # 1.0
x **= 3     # 1.0
x %= 1      # 0.0

s = "hi"
s += "!"    # "hi!"

lst = [1, 2]
lst += [3, 4]   # эквивалентно lst.extend([3, 4]) — мутирует список!
```

Тонкость: для **mutable** объектов `+=` мутирует на месте (вызывает `__iadd__`), для **immutable** — создаёт новый (через `__add__`):

```python
a = [1, 2]
b = a
a += [3]     # мутирует, b тоже [1, 2, 3]
print(b)     # [1, 2, 3]

a = (1, 2)
b = a
a += (3,)    # создаёт новый, b остался (1, 2)
print(b)     # (1, 2)
```

Знание этого спасает от часов отладки.

### `:=` — walrus

С Python 3.8 — присваивание-выражение. Можно «обнять» в условии:
```python
if (n := len(data)) > 10:
    print(f"много данных: {n}")

while (chunk := f.read(1024)):
    process(chunk)
```

## 7. Операторы для последовательностей и контейнеров

### `+` — конкатенация

```python
[1, 2] + [3, 4]    # [1, 2, 3, 4]
"hi" + " there"    # 'hi there'
(1, 2) + (3, 4)    # (1, 2, 3, 4)
```

Создаёт новый объект. Не работает между разными типами:
```python
[1, 2] + (3, 4)    # TypeError
```

### `*` — повторение

```python
[0] * 5            # [0, 0, 0, 0, 0]
"-" * 20           # '--------------------'
(None,) * 3        # (None, None, None)
```

**Подвох с mutable:**
```python
matrix = [[0] * 3] * 3      # ⚠️ ВНИМАНИЕ
print(matrix)               # [[0, 0, 0], [0, 0, 0], [0, 0, 0]]
matrix[0][0] = 99
print(matrix)               # [[99, 0, 0], [99, 0, 0], [99, 0, 0]] — все строки одинаковые!
```

Это потому, что `[[0]*3] * 3` создаёт **3 ссылки на один и тот же список**. Изменил первый — изменилось во всех.

Правильно — comprehension:
```python
matrix = [[0] * 3 for _ in range(3)]   # 3 независимых списка
```

### `in` для строк ищет **подстроку**

```python
"py" in "python"       # True
"" in "anything"       # True — пустая всегда in
```

## 8. Тернарный оператор

```python
result = "yes" if condition else "no"
```

Эквивалент:
```python
if condition:
    result = "yes"
else:
    result = "no"
```

Полезен для коротких выборов:
```python
status = "even" if n % 2 == 0 else "odd"
val = data[i] if 0 <= i < len(data) else None
```

Не злоупотребляй вложениями:
```python
# плохо
x = "a" if c1 else "b" if c2 else "c" if c3 else "d"
# лучше — обычные if/elif
```

## 9. Перегрузка операторов через dunder-методы

Когда ты пишешь `a + b`, Python вызывает `a.__add__(b)`. Если этот метод не определён или вернул `NotImplemented`, пробует `b.__radd__(a)` (right-add). Если оба не работают — `TypeError`.

| Оператор | Метод |
|---|---|
| `a + b` | `a.__add__(b)` |
| `a - b` | `a.__sub__(b)` |
| `a * b` | `a.__mul__(b)` |
| `a / b` | `a.__truediv__(b)` |
| `a // b` | `a.__floordiv__(b)` |
| `a % b` | `a.__mod__(b)` |
| `a ** b` | `a.__pow__(b)` |
| `-a` | `a.__neg__()` |
| `a == b` | `a.__eq__(b)` |
| `a < b` | `a.__lt__(b)` |
| `a & b` | `a.__and__(b)` |
| `a in b` | `b.__contains__(a)` |
| `a[i]` | `a.__getitem__(i)` |

Это позволяет написать **свой** класс, который ведёт себя как число:
```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)
    def __mul__(self, k):
        return Vector(self.x * k, self.y * k)
    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

a = Vector(1, 2)
b = Vector(3, 4)
print(a + b)          # Vector(4, 6)
print(a * 5)          # Vector(5, 10)
```

Подробно — в теме ООП. Но запомни: **операторы — это просто синтаксический сахар над методами**.

## 10. Сложение и mutable: `__add__` vs `__iadd__`

Для mutable-типов есть два разных метода:
- `__add__` — для `a + b` — возвращает **новый** объект.
- `__iadd__` — для `a += b` — модифицирует `a` на месте (если возможно) и возвращает self.

Если `__iadd__` не определён, `+=` падает обратно на `__add__` + переприсваивание.

```python
a = [1, 2]
b = [3, 4]
print(id(a))
a += b           # вызывает __iadd__, мутирует a
print(id(a))     # тот же id

a = (1, 2)
print(id(a))
a += (3, 4)      # tuple immutable, нет __iadd__, → __add__ → новый объект
print(id(a))     # новый id
```

Это объясняет «телепортацию» изменений через `+=` для списка vs «независимость» для тюпла.

## 11. Деление и точность

### Денежная арифметика

`float` теряет точность:
```python
0.1 + 0.2     # 0.30000000000000004
sum([0.1] * 10)   # 0.9999999999999999, не 1.0
```

Для денег используй `Decimal`:
```python
from decimal import Decimal, getcontext

getcontext().prec = 30

a = Decimal("0.1")
b = Decimal("0.2")
print(a + b)      # Decimal('0.3') — точно

amount = Decimal("100.00")
tax = Decimal("0.07")
total = amount * (1 + tax)
print(total)      # Decimal('107.0000') — точно
```

Создавай `Decimal` **из строки**, не из float (`Decimal(0.1)` уже потерял точность).

### Дроби

```python
from fractions import Fraction
a = Fraction(1, 3)
b = Fraction(2, 3)
print(a + b)      # Fraction(1, 1) — точно 1
print(a * 6)      # Fraction(2, 1)
```

Используется когда нужны точные рациональные вычисления (символьная математика, физика).

## 13. Сравнение разных типов

В Python 2 можно было `1 < "a"` — выдавало случайный результат. В Python 3 это **TypeError**:
```python
1 < "a"        # TypeError: '<' not supported between instances of 'int' and 'str'
```

Кроме int↔float и True/False↔1/0 — сравнения между разными типами запрещены.

`==` и `!=` работают: возвращают True/False всегда:
```python
1 == "1"      # False — не падает
None == 5     # False
[] == 0       # False
```

## 14. Распаковка и `*`/`**`

Звёздочки в Python — перегруженные операторы. Кроме умножения/степени, они означают:

### Распаковка в присваивании

```python
a, b = 1, 2
a, b = b, a            # обмен
a, *rest = [1, 2, 3]   # a=1, rest=[2,3]
*head, last = [1,2,3]  # head=[1,2], last=3
```

### Распаковка в вызовах

```python
def f(a, b, c):
    pass

args = [1, 2, 3]
f(*args)               # эквивалентно f(1, 2, 3)

kwargs = {"a": 1, "b": 2, "c": 3}
f(**kwargs)            # эквивалентно f(a=1, b=2, c=3)
```

### Распаковка в литералах (Python 3.5+)

```python
[*a, *b]            # объединить два списка
{*a, *b}            # объединить два множества
{**a, **b}          # объединить два словаря; b перекрывает a при совпадении ключей
(*a, *b)            # объединить два tuple
```

Это удобнее `+`, потому что работает между разными типами:
```python
list_data = [1, 2]
tuple_data = (3, 4)
combined = [*list_data, *tuple_data]   # [1, 2, 3, 4]
```

### `*args, **kwargs` в определении функций

```python
def f(*args, **kwargs):
    print(args)      # tuple позиционных
    print(kwargs)    # dict именованных

f(1, 2, 3, x=10)
# args = (1, 2, 3)
# kwargs = {'x': 10}
```

Подробно — в теме «Функции».

## 15. Оператор `@` — матричное умножение

С Python 3.5 — оператор `@` для матричного умножения. У встроенных типов не определён, но используется в numpy:
```python
import numpy as np
a = np.array([[1, 2], [3, 4]])
b = np.array([[5, 6], [7, 8]])
a @ b        # матричное произведение
```

Соответствующий dunder — `__matmul__`.

## 16. Типичные ошибки

### Целочисленное деление и пол

```python
n = -7
n // 2        # -4, не -3 — округление в минус бесконечность
abs(-7) // 2  # 3 — сначала abs, потом деление
```

### Проблемы с float

```python
0.1 + 0.2 == 0.3        # False
round(2.5)              # 2 (банковское округление!), не 3
```

### Перепутали `=` и `==`

```python
if x = 5:    # SyntaxError в Python (в C — это была бы тихая ловушка)
    ...
```

В Python `=` нельзя в условии (кроме walrus `:=`), это спасает.

### Цепочки сравнений с булевыми

```python
False == False == True   # False
```

### `1 in [True, False]` — True

Потому что `True == 1`. Так же `False in [0, 1]` тоже True.

## 17. Что нужно запомнить

- `/` — float, `//` — floor (вниз), не truncate.
- `%` следует знаку делителя.
- `**` право-ассоциативен.
- Сравнения цепляются: `1 < x < 10`.
- `and`/`or` короткозамкнуты и возвращают операнд, не True/False.
- `in` для list/str — O(n), для set/dict — O(1).
- `+=` для mutable мутирует, для immutable создаёт новый.
- `[[0]*n]*m` — общая бомба, делай через comprehension.
- `0.1 + 0.2 != 0.3` — никогда не сравнивай float через `==`.
- Все операторы — это вызовы dunder-методов под капотом.

С этими знаниями ты не будешь делать большинство типичных ошибок начинающих, и сможешь спокойно перейти к вводу-выводу и условиям.
