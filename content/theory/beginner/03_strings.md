# Строки — от 0 до 100%

Строки — самый универсальный тип данных в программировании. Любой ввод от пользователя — строка. Любой ответ HTTP-сервера — строка. Имена файлов, JSON, логи, конфиги, SQL-запросы — всё в строках. Поэтому работа со строками — навык, который ты будешь применять ежедневно.

В Python строки сделаны лучше, чем во многих других языках: они умеют Unicode из коробки, у них десятки удобных методов, и их синтаксис позволяет писать читабельный код. Но за этим удобством скрывается куча нюансов: кодировки, encode/decode, immutability, intern, форматирование. Разберём всё.

---

## 1. Что такое строка в Python

`str` — это **последовательность символов Unicode**. Не байтов, а именно символов. То есть `"привет"` — это 6 символов, а не 12 байт (хотя в UTF-8 русские буквы занимают 2 байта каждая).

Это принципиальное отличие от Python 2 и от многих других языков, где строка — массив байтов. В Python 3 различают:
- `str` — текст (последовательность Unicode-кодовых точек).
- `bytes` — двоичные данные (последовательность байт 0-255).

Преобразуются друг в друга через **кодировку**: `str.encode("utf-8") → bytes`, `bytes.decode("utf-8") → str`.

```python
s = "привет"
print(len(s))        # 6 — символов
b = s.encode("utf-8")
print(len(b))        # 12 — байт
print(b)             # b'\xd0\xbf\xd1\x80\xd0\xb8\xd0\xb2\xd0\xb5\xd1\x82'
```

Подробнее про кодировки — в секции 12.

## 2. Создание строк

```python
s1 = "двойные кавычки"
s2 = 'одинарные кавычки'
s3 = """тройные кавычки
позволяют сделать
многострочную строку"""
s4 = '''то же самое'''
```

Между `"..."` и `'...'` нет смысловой разницы — выбирай, чтобы не приходилось экранировать кавычки внутри:
```python
s = "He said 'hi'"     # без экранирования
s = 'She replied "hello"'
s = "She said \"hi\""  # пришлось экранировать
```

Тройные кавычки полезны для многострочного текста, docstrings (документации функций), и SQL/JSON шаблонов.

### Префиксы строк

```python
r"\n"           # raw — не интерпретирует \n как перевод строки, оставляет как два символа
b"hello"        # bytes
f"x={x}"        # f-string — подстановка переменных
u"hi"           # unicode (legacy, в Python 3 все строки уже unicode, префикс игнорируется)
rb"\n"          # raw bytes
```

Префиксы можно комбинировать: `rf"raw f-string {x}"`, `br"raw bytes"`, и т.д.

## 3. Escape-последовательности

В обычной строке (без префикса `r`) обратная косая черта запускает специальную последовательность:

| Запись | Что значит |
|---|---|
| `\n` | перевод строки (LF, 0x0A) |
| `\r` | возврат каретки (CR, 0x0D) |
| `\t` | табуляция (0x09) |
| `\b` | backspace (0x08) — стирает символ слева |
| `\f` | form feed (0x0C) |
| `\v` | vertical tab (0x0B) |
| `\a` | bell — пиликнуть в терминале (0x07) |
| `\0` | null (0x00) |
| `\\` | сам обратный слеш |
| `\'` | одинарная кавычка |
| `\"` | двойная кавычка |
| `\xHH` | байт в hex (`\x41` = `A`) |
| `\uHHHH` | unicode 16-bit (`\u00e9` = `é`) |
| `\UHHHHHHHH` | unicode 32-bit (`\U0001F600` = `😀`) |
| `\N{NAME}` | unicode по официальному имени (`\N{GREEK SMALL LETTER ALPHA}` = `α`) |

Подробно про каждый символ см. в теме «Print и базовый вывод» — там их применение.

### Raw strings

Префикс `r` отключает интерпретацию escape:

```python
print("C:\new\table")   # выведет с переводом строки и табом — мусор
print(r"C:\new\table")  # выведет как есть: C:\new\table
```

Используй raw для:
- путей в Windows: `r"C:\Users\admin"`
- регулярных выражений: `re.match(r"\d+", text)` — паттерны почти всегда содержат `\`
- LaTeX: `r"\sum_{i=0}^n"`

Ограничение raw: строка **не может заканчиваться** на нечётное число `\`. `r"abc\"` — синтаксическая ошибка.

## 4. Индексация и срезы

Строка — это последовательность, индексируется как массив:

```python
s = "Hello"
print(s[0])     # 'H'
print(s[4])     # 'o'
print(s[-1])    # 'o' — отрицательный индекс с конца
print(s[-5])    # 'H'
print(s[10])    # IndexError: string index out of range
```

### Срезы (slicing)

```python
s = "Hello, World!"
s[0:5]      # 'Hello'
s[7:12]     # 'World'
s[7:]       # 'World!'  — до конца
s[:5]       # 'Hello'   — от начала
s[:]        # 'Hello, World!'  — копия всей строки
s[::2]      # 'Hlo ol!'  — каждый второй символ
s[::-1]     # '!dlroW ,olleH'  — реверс строки
s[10:5:-1]  # 'roW ,'  — задом наперёд от 10 до 5+1
```

Формат: `s[start:stop:step]`. По умолчанию `start=0`, `stop=len(s)`, `step=1`. Срез **никогда не падает с IndexError**, даже если границы за пределами:

```python
"abc"[0:1000]   # 'abc' — нормально
"abc"[5:10]     # ''   — пустая строка, не ошибка
```

### Срез возвращает новую строку

Поскольку `str` immutable, любой срез создаёт **новый** объект:
```python
s = "hello world"
sub = s[:5]
print(id(s) == id(sub))   # False
```

## 5. Конкатенация и повторение

```python
"hi" + " " + "there"     # 'hi there'
"ab" * 3                 # 'ababab'
"ab" * 0                 # '' — ноль раз = пустая строка
"ab" * -1                # '' — отрицательное = пустая
```

### Цикл с конкатенацией — почему это плохо

```python
result = ""
for word in words:
    result += word + " "    # ⚠️ медленно для большого числа итераций
```

Каждая итерация создаёт новую строку и копирует все байты предыдущей → O(n²). Для маленьких циклов (десятки итераций) — пофиг, но для тысяч/миллионов — **используй `str.join()`**:

```python
result = " ".join(words)    # O(n)
```

CPython с версии 2.5 имеет небольшую оптимизацию для `s += x` в цикле (если на `s` единственная ссылка — мутирует на месте), но полагаться на неё не стоит: в PyPy и других реализациях её нет.

## 6. Сравнение и упорядочение

Строки сравниваются **лексикографически** (как в словаре), посимвольно, по их Unicode codepoints:

```python
"abc" < "abd"     # True — c (99) < d (100)
"abc" < "abcd"    # True — короче, при равенстве префикса
"Abc" < "abc"     # True — A (65) < a (97), большие буквы идут раньше
"яблоко" < "ёлка" # ?? — зависит от кодпоинта, в реальности False
```

Это **не зависит от языка/локали**. Для «правильной» сортировки кириллицы / с учётом регистра используй `locale.strcoll` или `key=str.lower`/`key=str.casefold`.

Полное сравнение всех методов:
- `==`, `!=`, `<`, `<=`, `>`, `>=` — по Unicode
- `s.lower()` — для регистронезависимого сравнения
- `s.casefold()` — более правильный lower для не-латинских скриптов (German ß → ss)
- `unicodedata.normalize` — для нормализации (см. 14)

```python
"Hello" == "hello"             # False
"Hello".lower() == "hello"     # True
"ß".lower() == "ss"            # False — lower не достаточно
"ß".casefold() == "ss"         # True — правильно
```

## 7. Поиск подстроки

```python
s = "Hello, World!"

"World" in s          # True
"world" in s          # False — case-sensitive
s.find("World")       # 7  — индекс или -1 если нет
s.find("xyz")         # -1
s.index("World")      # 7  — то же, но ValueError если нет
s.rfind("o")          # 8  — поиск с конца
s.count("o")          # 2  — сколько раз встречается
s.count("o", 5)       # 1  — поиск только в s[5:]
s.startswith("Hello") # True
s.endswith("!")       # True
s.startswith(("Hi","Hello"))  # True — можно tuple
```

`in` использует алгоритм Boyer-Moore-Horspool — очень быстрый.

## 8. Изменение регистра

```python
"Hello".lower()       # 'hello'
"Hello".upper()       # 'HELLO'
"hello world".title() # 'Hello World' — каждое слово с большой
"hello".capitalize()  # 'Hello' — только первая буква строки
"Hello".swapcase()    # 'hELLO'
"HELLO".casefold()    # 'hello' — для строгого сравнения
```

`title()` опасен в реальном тексте: `"it's a test".title()` → `"It'S A Test"` (апостроф трактуется как разделитель). Для людей лучше делать вручную.

## 9. Чистка пробелов и обрезка

```python
"  hello  ".strip()       # 'hello' — пробелы и \n с обеих сторон
"  hello  ".lstrip()      # 'hello  '
"  hello  ".rstrip()      # '  hello'
"###hello###".strip("#")  # 'hello' — указываем что снимать
"abcXabc".strip("abc")    # 'X' — снимает все символы из набора, не подстроку!
```

`strip("abc")` не «снимает 'abc'» — он снимает любые из символов a, b, c. Это часто путает.

### `removeprefix` и `removesuffix` (Python 3.9+)

```python
"prefix_data".removeprefix("prefix_")  # 'data'
"file.txt".removesuffix(".txt")        # 'file'
"data".removeprefix("prefix_")         # 'data' — нет префикса, ничего не делает
```

Раньше писали:
```python
if s.startswith("prefix_"):
    s = s[len("prefix_"):]
```

Теперь — одна строка.

## 10. Замена и разделение

### `replace`

```python
"hello world".replace("world", "Python")   # 'hello Python'
"aaa".replace("a", "bb")                   # 'bbbbbb'
"aaaa".replace("a", "b", 2)                # 'bbaa' — только первые 2 замены
```

Замены — **не регулярки**. Для regex — модуль `re`.

### `split`

```python
"a,b,c".split(",")            # ['a', 'b', 'c']
"a, b , c".split(",")         # ['a', ' b ', ' c'] — пробелы остаются!
"hello world".split()         # ['hello', 'world'] — без аргумента: по любым пробелам
"  a   b  ".split()           # ['a', 'b'] — все группы whitespace, и краевые игнор
"a,b,,c".split(",")           # ['a', 'b', '', 'c'] — пустая строка между ',,' сохраняется
"a:b:c".split(":", 1)         # ['a', 'b:c'] — макс 1 разделение
"a\nb\nc".splitlines()        # ['a', 'b', 'c'] — по любым переводам строк (универсально)
```

`split()` без аргумента vs `split(" ")` — **разные**. Без аргумента — умный разделитель по пробелам с дроп пустых элементов. С аргументом `" "` — буквально по одиночному пробелу, оставляет пустые.

### `rsplit`, `partition`

```python
"a-b-c".rsplit("-", 1)     # ['a-b', 'c'] — split с конца
"a=b=c".partition("=")     # ('a', '=', 'b=c') — три части: до, разделитель, после
"abc".partition("=")       # ('abc', '', '') — нет разделителя
```

### `join`

Обратная операция `split`:
```python
", ".join(["a", "b", "c"])   # 'a, b, c'
"".join(["a", "b", "c"])     # 'abc'
"-".join("xyz")              # 'x-y-z' — строка тоже итерируема
```

`join` принимает только итерируемое из строк. `", ".join([1, 2, 3])` — TypeError.

## 11. Форматирование строк — четыре способа

### Способ 1: `%`-форматирование (старый, как в C)

```python
"Hello, %s! You are %d years old" % ("Alice", 30)
"%.2f" % 3.14159   # '3.14'
"%05d" % 42        # '00042'
```

Древний синтаксис, до сих пор работает. Не используй в новом коде.

### Способ 2: `str.format()`

```python
"Hello, {}! You are {} years old".format("Alice", 30)
"{0} {1} {0}".format("a", "b")              # 'a b a' — нумерованные
"{name} is {age}".format(name="Alice", age=30)
"{:.2f}".format(3.14159)                     # '3.14'
```

Был популярен в Python 2.6-3.5. Сейчас почти везде вытеснен f-strings, но тебе встретится в legacy коде.

### Способ 3: f-strings (Python 3.6+) — основной

```python
name = "Alice"
age = 30
f"Hello, {name}! You are {age} years old"
f"{age + 5}"                  # выражение прямо внутри
f"{age:5d}"                   # ширина 5
f"{3.14159:.2f}"              # 2 знака после запятой
f"{42:08b}"                   # двоичное, ширина 8 с нулями: '00101010'
f"{name!r}"                   # repr (с кавычками): "'Alice'"
f"{name=}"                    # 'name=Alice' — Python 3.8+, для дебага
```

Полный мини-язык внутри `{}`:
```
{value:[fill][align][sign][#][0][width][,][.precision][type]}
```

Примеры:
```python
f"{42:>10}"      # '        42'   правый выравн., ширина 10
f"{42:<10}"      # '42        '   левый
f"{42:^10}"      # '    42    '   центр
f"{42:*^10}"     # '****42****'   центр с заполнением *
f"{1234567:,}"   # '1,234,567'    группы тысяч
f"{0.5:.2%}"     # '50.00%'        процент
f"{255:#x}"      # '0xff'          с префиксом
f"{255:08b}"     # '11111111'      двоичное с нулями до 8
f"{date:%Y-%m-%d}"   # для datetime — кастомный формат
```

f-strings **самые быстрые** из четырёх способов — Python компилирует их в очень эффективный байткод.

### Способ 4: Template strings (`string.Template`)

```python
from string import Template
t = Template("Hello, $name!")
t.substitute(name="Alice")    # 'Hello, Alice!'
```

Безопасен для пользовательского ввода (нет выполнения кода), но беднее по возможностям. Используется редко, в основном в шаблонизаторах.

## 12. Кодировки: encode и decode

`str` — это абстрактные «символы». Чтобы записать строку в файл или отправить по сети, её надо превратить в **байты** — конкретное двоичное представление. Это и есть кодировка.

### UTF-8 — стандарт де-факто

Используй её **везде** где можешь. Свойства:
- ASCII-символы (a-z, 0-9) занимают 1 байт.
- Кириллица — 2 байта на символ.
- Большинство восточных языков — 3 байта.
- Эмодзи и редкие символы — 4 байта.
- Совместима с ASCII (можно открыть UTF-8 файл, содержащий только английский, как ASCII).

```python
s = "Привет, 🌍!"
b = s.encode("utf-8")
print(b)               # b'\xd0\x9f...'
print(len(b))          # 14 байт
back = b.decode("utf-8")
print(back == s)       # True
```

### Другие кодировки

- `cp1251` (Windows-1251) — старая русская однобайтовая. Кодирует 256 символов, поэтому помещается только латиница + кириллица. До сих пор встречается в легаси.
- `koi8-r` — древняя «советская» кодировка, теперь редкость.
- `cp866` — DOS-кодировка для русского.
- `latin-1` (ISO-8859-1) — однобайтовая для западноевропейских языков. Ловкий лайфхак: `bytes.decode("latin-1")` **никогда не падает**, потому что любой байт 0-255 имеет соответствие. Иногда используется чтобы сохранить «сырые» байты в строке.
- `utf-16`, `utf-32` — Unicode фиксированной длины. Используются Windows API, Java, JavaScript.

### `encode` / `decode`

```python
s = "Привет"
s.encode("utf-8")       # b'\xd0\x9f...'
s.encode("cp1251")      # b'\xcf\xf0\xe8\xe2\xe5\xf2'
s.encode("ascii")       # UnicodeEncodeError: 'ascii' codec can't encode

b = b"\xcf\xf0\xe8\xe2\xe5\xf2"
b.decode("cp1251")      # 'Привет'
b.decode("utf-8")       # UnicodeDecodeError: invalid start byte
```

### Стратегия при ошибках

Параметр `errors`:
```python
"Привет".encode("ascii", errors="ignore")     # b'' — выкидывает что не помещается
"Привет".encode("ascii", errors="replace")    # b'??????' — заменяет на ?
"Привет".encode("ascii", errors="backslashreplace")  # b'\\u041f\\u0440\\u0438...' — escape
b"\xff".decode("utf-8", errors="replace")     # '�' — replacement character
```

`errors="strict"` (по умолчанию) — падать с исключением. Это **правильное поведение** — тихое игнорирование портит данные.

## 13. ord, chr, hex

```python
ord("A")           # 65 — кодпоинт символа
ord("я")           # 1103
ord("🌍")          # 127757

chr(65)            # 'A'
chr(1103)          # 'я'
chr(127757)        # '🌍'

hex(127757)        # '0x1f30d'
"\U0001f30d"       # '🌍' — то же самое через escape
```

Все символы Unicode имеют кодпоинт от 0 до 0x10FFFF (1 114 111). Распределены по плоскостям (planes), языкам, эмодзи и т.д.

## 14. Нормализация Unicode

Один и тот же видимый символ может быть представлен разными последовательностями codepoints. Например, буква `é`:
- `\u00e9` — один кодпоинт (precomposed)
- `\u0065\u0301` — два кодпоинта: `e` + комбинирующий accent

Они визуально идентичны, но `==` вернёт False:
```python
a = "é"             # \u00e9
b = "e\u0301"       # e + combining
print(a == b)       # False
print(len(a), len(b))  # 1, 2
```

Решение — нормализация:
```python
import unicodedata
unicodedata.normalize("NFC", a) == unicodedata.normalize("NFC", b)   # True
```

Формы нормализации:
- **NFC** — composed (короткая). Для отображения пользователю.
- **NFD** — decomposed (длинная). Для алгоритмических манипуляций.
- **NFKC**, **NFKD** — «совместимые» — сворачивают визуально похожие символы (например, `①` → `1`, `ﬁ` → `fi`). Полезно для поиска.

При сравнении строк, особенно из разных источников (имена файлов с macOS vs Linux), нормализуй обе.

## 15. Полезные методы для проверки

```python
"abc".isalpha()        # True — все буквы
"123".isdigit()        # True — все цифры (только ASCII 0-9 и некоторые Unicode)
"abc123".isalnum()     # True — буквы и/или цифры
"   ".isspace()        # True — только whitespace
"".isspace()           # False — пустая строка
"hello".islower()      # True
"HELLO".isupper()      # True
"Hello".istitle()      # True — каждое слово с большой
"abc".isascii()        # True — Python 3.7+
"123".isdecimal()      # True — только десятичные цифры
"½".isnumeric()        # True — любые числовые (включая дроби)
"abc".isidentifier()   # True — годится как имя переменной
"if".isidentifier()    # True — но это keyword!
"if".iskeyword()       # требует keyword.iskeyword("if") — True
```

Различие `isdigit`/`isdecimal`/`isnumeric` тонкое:
- `isdecimal` — только 0-9 и их Unicode-аналоги в других системах счисления
- `isdigit` — добавляет верхние/нижние индексы (²,³)
- `isnumeric` — добавляет дроби (½), римские (Ⅻ), и т. д.

Для парсинга чисел из ввода — `isdecimal`.

## 16. Bytes — бинарные данные

`bytes` — неизменяемая последовательность байт (0-255).

```python
b = b"hello"
print(b[0])         # 104 — это int, не str!
print(b[0:3])       # b'hel'
print(len(b))       # 5

# создание
b = bytes([72, 101, 108, 108, 111])  # b'Hello'
b = bytes(5)                          # b'\x00\x00\x00\x00\x00' — 5 нулей

# методы аналогичны str
b.decode("utf-8")   # 'hello'
b.upper()           # b'HELLO'
```

`bytearray` — то же самое, но **изменяемое** (mutable):
```python
ba = bytearray(b"hello")
ba[0] = 72   # 'H'
print(ba)    # bytearray(b'Hello')
```

Используются для:
- работы с файлами (`open(file, "rb")` возвращает bytes);
- сети (сокеты передают байты);
- бинарных протоколов (struct, msgpack, protobuf);
- криптографии (хеши, подписи).

## 17. Длина и память

`len(s)` для `str` — количество символов (codepoints), не байт. Сложность — O(1), потому что Python хранит длину явно в заголовке объекта.

### Внутреннее представление (PEP 393, Python 3.3+)

Python автоматически выбирает самое компактное представление:
- Только ASCII (≤ 127): 1 байт на символ
- Только BMP (≤ 0xFFFF, кириллица сюда входит): 2 байта на символ
- Любые Unicode (включая эмодзи): 4 байта на символ

```python
import sys
sys.getsizeof("hello")            # 54 — 1 байт/символ + заголовок
sys.getsizeof("привет")           # 86 — 2 байта/символ
sys.getsizeof("hello🌍")          # ~80 — переключается на 4 байта/символ
```

Для строки с одним эмодзи в конце вся строка хранится в 4-байтном представлении — нельзя «смешать» режимы.

### Intern

Короткие «имя-подобные» строки автоматически интернируются:
```python
a = "hello"
b = "hello"
a is b      # True — interned

a = sys.intern("hello world!")
b = sys.intern("hello world!")
a is b      # True — принудительно интернированы
```

Полезно для оптимизации памяти, когда у тебя миллион одинаковых ключей в словаре.

## 18. Regex — короткое введение

Для поиска по шаблонам — модуль `re`:
```python
import re

re.search(r"\d+", "abc 123 def")           # Match object, group(0) = '123'
re.findall(r"\d+", "1 cat, 2 dogs")        # ['1', '2']
re.sub(r"\s+", " ", "a   b\tc")            # 'a b c'
re.split(r"[,;]", "a,b;c,d")               # ['a', 'b', 'c', 'd']
m = re.match(r"(\w+)@(\w+)", "alice@example")
m.group(1), m.group(2)                      # ('alice', 'example')
```

Полный учебник по regex — отдельная тема, но базовые синтаксис:
- `.` — любой символ кроме \n
- `\d`, `\w`, `\s` — цифра, символ слова, whitespace
- `*`, `+`, `?` — 0+, 1+, 0 или 1 повторов
- `^`, `$` — начало и конец строки
- `[abc]`, `[a-z]` — символ из набора
- `(...)` — группа
- `{n,m}` — от n до m повторов

Используй raw-strings: `r"\d+"`, иначе `\d` будет требовать удвоения слешей.

## 19. Типичные ошибки

**Сравнение строк по `is`**:
```python
s = input()
if s is "yes":      # ⚠️ может быть True, может False — никогда не пиши так
    ...
if s == "yes":      # ✅
    ...
```

**Конкатенация в цикле**:
```python
result = ""
for word in big_list:
    result += word    # медленно для длинных списков
# вместо этого:
result = "".join(big_list)
```

**Перепутали `split()` и `split(" ")`**:
```python
"  a  b  ".split()      # ['a', 'b']
"  a  b  ".split(" ")   # ['', '', 'a', '', 'b', '', '']
```

**Не нормализовали Unicode**:
```python
file.txt из macOS  != file.txt с Linux  # потому что macOS использует NFD, Linux NFC
```

**Decode без указания кодировки**:
```python
b = b"\xd0\x9f"
b.decode()        # по умолчанию UTF-8 — работает
b.decode("ascii") # UnicodeDecodeError
```

Всегда явно указывай `encoding="utf-8"` при работе с файлами и сетью.

**Использование `%` форматирования вместо f-string в новом коде** — устарело.
