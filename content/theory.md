## 1. Что такое Python и зачем он нужен

**Python** — высокоуровневый интерпретируемый язык программирования общего назначения. Создан Гвидо ван Россумом, первый релиз — 1991 год.

Ключевые особенности:

- **Простой и читаемый синтаксис.** Отступы заменяют фигурные скобки `{}`, как в C/Java.
- **Динамическая типизация.** Тип переменной определяется во время выполнения, а не указывается заранее.
- **Интерпретируемый.** Код выполняется построчно интерпретатором — не нужно компилировать программу в машинный код вручную.
- **Кроссплатформенный.** Один и тот же скрипт работает на Windows, macOS, Linux.
- **Огромная стандартная библиотека.** «Батарейки в комплекте» — для работы с файлами, сетью, JSON, датами и т. д.
- **Гигантская экосистема пакетов** через индекс PyPI: веб (Django, Flask, FastAPI), наука/ML (NumPy, pandas, PyTorch), автоматизация, парсинг и т. д.

Для чего реально применяют Python:

- веб-разработка (бэкенд);
- анализ данных, машинное обучение, нейросети;
- автоматизация рутины, скрипты;
- DevOps и системное администрирование;
- обучение программированию (его специально часто берут как первый язык).

> **Важно:** в этой методичке мы используем **Python 3** (актуальные версии — 3.10+). Python 2 устарел и официально не поддерживается с 2020 года. Никогда не учите Python 2.

## 2. Установка Python и первая программа

### 2.1. Установка

- **Windows:** скачайте установщик с [python.org/downloads](https://www.python.org/downloads/). При установке **обязательно поставьте галочку «Add Python to PATH»**, иначе команда `python` не будет видна в терминале.
- **macOS:** проще всего через [Homebrew](https://brew.sh): `brew install python`.
- **Linux (Ubuntu/Debian):** `sudo apt update && sudo apt install python3 python3-pip`.

Проверка установки в терминале:

```bash
python --version
# или
python3 --version
```

Должно вывести что-то вроде `Python 3.12.3`.

### 2.2. Где писать код

Варианты от простого к удобному:

1. **Интерактивный интерпретатор (REPL):** введите в терминале `python` и пишите выражения — они тут же выполняются. Удобно для быстрых проверок.
2. **Файл `.py`:** напишите код в текстовом редакторе и сохраните, например, как `hello.py`. Запуск: `python hello.py`.
3. **IDE/редактор:** [VS Code](https://code.visualstudio.com/) с расширением Python, или [PyCharm Community](https://www.jetbrains.com/pycharm/). Рекомендуется именно VS Code как универсальный и бесплатный.

### 2.3. Программа №1 — «Hello, World!»

Создайте файл `hello.py` и запишите туда:

```python
print("Hello, World!")
```

Запустите в терминале:

```bash
python hello.py
```

Вывод:

```
Hello, World!
```

**Разбор каждой части:**

- `print` — встроенная **функция** Python. Функция — это блок кода, который что-то делает; в данном случае выводит данные на экран (в стандартный поток вывода).
- `(...)` — круглые скобки означают **вызов** функции. Внутри скобок передаются **аргументы** — данные, с которыми функция работает.
- `"Hello, World!"` — это **строка** (тип данных `str`). Строка — это последовательность символов в кавычках. В Python кавычки могут быть двойными `"..."` или одинарными `'...'` — разницы нет, выбирайте по удобству.
- В конце строки **не нужен** знак `;` (в отличие от C/Java/JS). Просто перенос строки = конец инструкции.

**Что делает интерпретатор:**

1. Читает файл `hello.py` сверху вниз.
2. Видит инструкцию `print("Hello, World!")`.
3. Вызывает функцию `print` с аргументом-строкой.
4. Функция отправляет строку в стандартный вывод (терминал) и автоматически добавляет перенос строки (`\n`).

**Мини-задание:** напишите программу, которая выводит ваше имя и любимое число.

## 3. Синтаксис, отступы и комментарии

### 3.1. Отступы — это часть синтаксиса

В большинстве языков блоки кода ограничиваются `{}`. В Python — **отступами** (обычно 4 пробела). Это не стиль, а **обязательное правило**.

```python
if 5 > 2:
    print("Пять больше двух")   # эта строка — внутри блока if, у неё отступ
print("Это уже снаружи if")     # у этой строки отступа нет
```

Если перепутать отступы — получите `IndentationError`. Используйте **4 пробела**, не табуляцию (хотя можно и табы — но не смешивайте).

### 3.2. Комментарии

Комментарии — это пояснения для человека, интерпретатор их игнорирует.

```python
# Это однострочный комментарий — всё после # до конца строки
print("Hello")  # комментарий можно писать и в конце строки кода

"""
Это многострочная строка.
Технически это не комментарий, а строковый литерал,
но его часто используют как многострочный комментарий или docstring.
"""
```

**Зачем комментарии?**

- Объяснить *почему* написан тот или иной код (а не *что* — это и так видно).
- Оставить TODO-пометку для будущего себя.
- Документировать функции и классы (для этого используют **docstring** — строку в начале функции).

### 3.3. Регистр имеет значение

`name`, `Name` и `NAME` — три разных переменных. Python чувствителен к регистру.

### 3.4. Несколько инструкций в одной строке

Можно через `;`, но **не делайте так** — это плохой тон:

```python
a = 1; b = 2; print(a + b)   # технически работает, но некрасиво
```

Правильно — каждая инструкция на своей строке.

## 4. Переменные и типы данных

### 4.1. Что такое переменная

**Переменная** — это имя, которое ссылается на значение в памяти. В Python:

```python
age = 25
name = "Алиса"
pi = 3.14
is_admin = True
```

- Слева от `=` — имя переменной.
- `=` — оператор **присваивания** (не равенства!).
- Справа — значение.

Тип указывать **не нужно** — Python сам определит его из значения. Это и называется **динамическая типизация**.

```python
x = 10        # x — целое число (int)
x = "Привет"  # теперь x — строка (str). Так можно, но лучше избегать смены типа
```

### 4.2. Правила именования

- Только латинские буквы, цифры, подчёркивание `_`.
- Не может начинаться с цифры: `2name` — ошибка, `name2` — ок.
- Не должно совпадать с **ключевыми словами** языка (`if`, `for`, `class`, `def`, `True`, `False`, `None` и т. д.).
- Стиль: **snake_case** (`user_name`, `total_count`), а не camelCase.
- Имя должно быть осмысленным: `n` — плохо, `student_count` — хорошо.

### 4.3. Основные встроенные типы

| Тип       | Что хранит                              | Примеры                           |
|-----------|----------------------------------------|-----------------------------------|
| `int`     | Целые числа                            | `0`, `42`, `-7`, `1_000_000`      |
| `float`   | Числа с плавающей точкой               | `3.14`, `-0.5`, `2.0`, `1e6`      |
| `bool`    | Логический тип: `True` или `False`     | `True`, `False`                   |
| `str`     | Строка (последовательность символов)   | `"hello"`, `'world'`              |
| `list`    | Список (изменяемый, упорядоченный)     | `[1, 2, 3]`, `["a", "b"]`         |
| `tuple`   | Кортеж (неизменяемый, упорядоченный)   | `(1, 2, 3)`                       |
| `dict`    | Словарь (ключ → значение)              | `{"name": "Алиса", "age": 25}`    |
| `set`     | Множество (без повторов, неупорядоч.)  | `{1, 2, 3}`                       |
| `NoneType`| Специальный тип «ничего»               | `None`                            |

Узнать тип переменной можно функцией `type()`:

```python
x = 42
print(type(x))         # <class 'int'>
print(type("hello"))   # <class 'str'>
print(type(3.14))      # <class 'float'>
```

### 4.4. Преобразование типов (приведение)

Иногда нужно превратить значение одного типа в другой:

```python
age_str = "25"             # это строка, не число
age_int = int(age_str)     # int("25") -> 25, теперь это число
age_float = float(age_str) # 25.0
print(age_int + 5)         # 30

n = 100
s = str(n)                 # "100" — теперь строка, можно конкатенировать
print("Тебе " + s + " лет")
```

Если строку нельзя превратить в число — будет ошибка `ValueError`:

```python
int("abc")  # ValueError: invalid literal for int()
```

### 4.5. Константы

В Python нет настоящих констант. По соглашению переменные, которые не должны меняться, пишут **БОЛЬШИМИ_БУКВАМИ**:

```python
PI = 3.14159
MAX_USERS = 1000
```

Технически их всё ещё можно изменить, но программист, увидев такое имя, не будет этого делать.

## 5. Операторы

### 5.1. Арифметические

```python
a = 10
b = 3

print(a + b)   # 13   — сложение
print(a - b)   # 7    — вычитание
print(a * b)   # 30   — умножение
print(a / b)   # 3.333... — деление (всегда float, даже если делится нацело)
print(a // b)  # 3    — целочисленное деление (отбрасывает дробную часть)
print(a % b)   # 1    — остаток от деления (модуль)
print(a ** b)  # 1000 — возведение в степень (10^3)
```

### 5.2. Сравнения (возвращают `bool`)

```python
print(5 == 5)   # True   — равно
print(5 != 3)   # True   — не равно
print(5 > 3)    # True   — больше
print(5 < 3)    # False
print(5 >= 5)   # True   — больше или равно
print(5 <= 4)   # False
```

⚠️ Важно: `=` — это **присваивание**, а `==` — **сравнение**. Самая частая ошибка новичков.

### 5.3. Логические

```python
x = True
y = False

print(x and y)   # False — И (and): True, только если оба True
print(x or y)    # True  — ИЛИ (or): True, если хотя бы один True
print(not x)     # False — НЕ (not): инвертирует значение
```

Логические операторы в Python работают **с короткой схемой** (short-circuit):

```python
# Если первая часть False, вторая даже не вычисляется
result = False and dangerous_function()  # dangerous_function НЕ вызовется

# Если первая часть True, вторая не вычисляется
result = True or dangerous_function()    # dangerous_function НЕ вызовется
```

### 5.4. Присваивания

```python
x = 5
x += 3   # x = x + 3  → 8
x -= 1   # x = x - 1  → 7
x *= 2   # x = x * 2  → 14
x /= 4   # x = x / 4  → 3.5
x //= 1  # x = x // 1 → 3.0
x %= 2   # остаток
x **= 2  # возведение в степень
```

### 5.5. Принадлежность и тождественность

```python
fruits = ["apple", "banana"]
print("apple" in fruits)      # True   — есть ли элемент в коллекции
print("cherry" not in fruits) # True

a = [1, 2, 3]
b = a            # b ссылается на тот же объект, что и a
c = [1, 2, 3]    # отдельный объект, но с теми же значениями

print(a == b)    # True  — равны по значению
print(a == c)    # True  — равны по значению
print(a is b)    # True  — это один и тот же объект в памяти
print(a is c)    # False — разные объекты, хоть и с одинаковыми значениями
```

Правило: для сравнения значений используйте `==`, для проверки «это тот же объект?» — `is`. Для `None` всегда пишите `x is None`, а не `x == None`.

## 6. Строки и форматирование

Строка (`str`) — последовательность символов. Кавычки — двойные, одинарные или тройные:

```python
s1 = "hello"
s2 = 'world'
s3 = """многострочная
строка"""
```

### 6.1. Конкатенация и повторение

```python
greet = "Привет, " + "мир!"   # "Привет, мир!"
line = "-" * 20                # "--------------------"
```

### 6.2. Длина, индексация, срезы

```python
s = "Python"

print(len(s))    # 6 — длина
print(s[0])      # 'P' — первый символ (индексация с 0!)
print(s[-1])     # 'n' — последний символ (отрицательные индексы — с конца)

# Срез s[start:stop:step] — выбирает подстроку
print(s[0:3])    # 'Pyt'  — символы с 0 по 2 (3 не включается)
print(s[2:])     # 'thon' — с 2 до конца
print(s[:4])     # 'Pyth' — с начала до 4
print(s[::-1])   # 'nohtyP' — переворот строки (шаг -1)
```

Строки **неизменяемы** (immutable): `s[0] = "X"` вызовет ошибку. Чтобы «изменить» строку — создаём новую.

### 6.3. Полезные методы

```python
s = "  Hello, World!  "

print(s.lower())          # '  hello, world!  '
print(s.upper())           # '  HELLO, WORLD!  '
print(s.strip())           # 'Hello, World!' — убрать пробелы по краям
print(s.replace("Hello", "Bye"))  # '  Bye, World!  '
print(s.split(","))        # ['  Hello', ' World!  '] — разбить по разделителю
print(",".join(["a","b","c"]))    # 'a,b,c' — собрать список в строку
print("World" in s)        # True — поиск подстроки
print(s.startswith("  H")) # True
print(s.endswith("!  "))   # True
print(len(s))              # длина
```

### 6.4. Форматирование строк

В Python 3.6+ предпочтительно использовать **f-строки** (f-strings):

```python
name = "Алиса"
age = 25

# 1. f-строки (рекомендуется)
print(f"Меня зовут {name}, мне {age} лет")
print(f"Через год будет {age + 1}")  # внутри {} можно писать выражения

# 2. метод .format() (старый, но встречается)
print("Меня зовут {}, мне {} лет".format(name, age))
print("Меня зовут {n}, мне {a} лет".format(n=name, a=age))

# 3. %-форматирование (наследие от C, в новом коде не используйте)
print("Меня зовут %s, мне %d лет" % (name, age))
```

Управление видом числа в f-строках:

```python
pi = 3.1415926535
print(f"{pi:.2f}")      # 3.14    — 2 знака после запятой
print(f"{pi:10.2f}")    # '      3.14' — ширина поля 10
print(f"{42:05d}")      # 00042   — целое с ведущими нулями
print(f"{0.85:.0%}")    # 85%     — проценты
```

### 6.5. Спецсимволы (escape-последовательности)

```python
print("Перенос\nстроки")      # \n — новая строка
print("Табуляция\tздесь")     # \t — табуляция
print("Кавычка \" внутри")    # \" — экранирование кавычки
print("Обратный слэш: \\")    # \\ — обратный слэш

# raw-строка: спецсимволы не интерпретируются (полезно для regex и путей Windows)
print(r"C:\Users\name")        # C:\Users\name  (без r было бы \U как escape)
```

## 7. Ввод и вывод

### 7.1. Вывод: `print()`

```python
print("Hello")                          # Hello
print("a", "b", "c")                    # a b c   — несколько аргументов через пробел
print("a", "b", sep="-")                # a-b      — разделитель
print("без переноса", end="")           # без переноса (без \n в конце)
print("следующее в той же строке")
```

Параметры функции `print`:

- `*objects` — что выводить;
- `sep=" "` — разделитель между аргументами (по умолчанию пробел);
- `end="\n"` — что добавить в конце (по умолчанию перенос);
- `file=sys.stdout` — куда выводить (можно в файл).

### 7.2. Ввод: `input()`

```python
name = input("Как тебя зовут? ")     # выводит подсказку и ждёт ввода
print(f"Привет, {name}!")
```

⚠️ Очень важно: `input()` всегда возвращает **строку**, даже если пользователь ввёл число.

```python
age = input("Возраст: ")     # допустим, ввели 25
print(age + 1)               # ОШИБКА: cannot concatenate str and int

# Правильно: явно преобразовать к числу
age = int(input("Возраст: "))
print(age + 1)               # 26
```

## 8. Условные конструкции

### 8.1. `if`, `elif`, `else`

```python
age = int(input("Возраст: "))

if age < 0:
    print("Так не бывает")
elif age < 18:
    print("Несовершеннолетний")
elif age < 65:
    print("Взрослый")
else:
    print("Пенсионер")
```

Как читается:

- `if условие:` — если условие истинно, выполнить блок.
- `elif условие:` — иначе, если другое условие истинно (можно много раз).
- `else:` — иначе во всех остальных случаях.

Двоеточие `:` обязательно, тело блока — с отступом.

### 8.2. Истинность значений (truthy / falsy)

В условии можно писать не только сравнения, но и любое значение. Python сам приведёт к `bool`:

**Falsy** (считаются ложью): `False`, `None`, `0`, `0.0`, `""`, `[]`, `{}`, `()`, `set()`.
Всё остальное — **truthy**.

```python
name = input("Имя: ")
if name:                # пустая строка — False, непустая — True
    print(f"Привет, {name}")
else:
    print("Ты не ввёл имя")
```

### 8.3. Цепочки сравнений

В Python можно писать так, как пишут в математике:

```python
x = 7
if 0 < x < 10:          # эквивалент: 0 < x and x < 10
    print("в диапазоне")
```

### 8.4. Тернарный оператор

Короткая форма if/else в одну строку:

```python
age = 20
status = "взрослый" if age >= 18 else "ребёнок"
print(status)
```

### 8.5. `match`/`case` (с Python 3.10)

Аналог switch из других языков, с расширенными возможностями (паттерн-матчинг):

```python
command = input("Команда: ")

match command:
    case "start":
        print("Запускаем")
    case "stop":
        print("Останавливаем")
    case "status" | "info":          # несколько вариантов
        print("Всё ок")
    case _:                          # _ — «всё остальное» (default)
        print("Неизвестная команда")
```

**Мини-задание:** программа определяет, является ли число положительным, отрицательным или нулём.

## 9. Циклы

Цикл — повторение блока кода. В Python два вида: `for` и `while`.

### 9.1. `for` — обход по коллекции

```python
fruits = ["яблоко", "банан", "вишня"]
for fruit in fruits:
    print(fruit)
```

`for x in коллекция:` — на каждой итерации `x` принимает значение очередного элемента.

Часто используют с функцией `range()`:

```python
range(5)         # 0, 1, 2, 3, 4
range(2, 7)      # 2, 3, 4, 5, 6
range(0, 10, 2)  # 0, 2, 4, 6, 8 — шаг 2
range(10, 0, -1) # 10, 9, ..., 1 — обратный отсчёт

for i in range(5):
    print(i)     # выведет 0,1,2,3,4

for i in range(1, 11):
    print(f"{i} в квадрате = {i**2}")
```

`enumerate()` — даёт индекс и значение одновременно:

```python
for i, fruit in enumerate(["a", "b", "c"]):
    print(i, fruit)
# 0 a
# 1 b
# 2 c
```

### 9.2. `while` — пока условие истинно

```python
count = 0
while count < 5:
    print(count)
    count += 1   # ВАЖНО! не забыть менять переменную, иначе бесконечный цикл
```

### 9.3. `break` и `continue`

```python
for n in range(10):
    if n == 5:
        break        # выйти из цикла полностью
    print(n)         # 0,1,2,3,4

for n in range(10):
    if n % 2 == 0:
        continue     # перейти к следующей итерации
    print(n)         # 1,3,5,7,9 — только нечётные
```

### 9.4. `else` у цикла

Редко используемая фича: блок `else` после цикла выполнится, **если цикл завершился нормально, без `break`**:

```python
for n in range(5):
    if n == 100:
        break
else:
    print("break не сработал — цикл прошёл до конца")
```

### 9.5. Бесконечный цикл и выход из него

```python
while True:
    answer = input("Введите 'quit' для выхода: ")
    if answer == "quit":
        break
    print(f"Вы ввели: {answer}")
```

## 10. Коллекции: списки, кортежи, словари, множества

### 10.1. Списки (`list`)

Упорядоченная **изменяемая** коллекция любых элементов.

```python
nums = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True, [1, 2]]   # элементы могут быть разных типов
empty = []

# Доступ и срезы — как у строк
print(nums[0])      # 1
print(nums[-1])     # 5
print(nums[1:4])    # [2, 3, 4]

# Изменение
nums[0] = 100        # [100, 2, 3, 4, 5]

# Основные методы
nums.append(6)       # добавить в конец → [..., 6]
nums.insert(0, 0)    # вставить по индексу → [0, ...]
nums.remove(2)       # удалить первое вхождение значения 2
last = nums.pop()    # удалить и вернуть последний элемент
nums.sort()          # отсортировать на месте
nums.reverse()       # перевернуть на месте
print(len(nums))     # длина
print(sum(nums))     # сумма
print(max(nums), min(nums))
```

### 10.2. Кортежи (`tuple`)

Как список, но **неизменяемый**. Используется, когда набор значений — единое целое (координаты, ключи и т. п.).

```python
point = (10, 20)
print(point[0])            # 10
# point[0] = 5             # TypeError — менять нельзя

# Распаковка
x, y = point
print(x, y)                # 10 20

# Кортеж из одного элемента — обязательно с запятой
t = (5,)                   # без запятой это просто число в скобках
```

### 10.3. Словари (`dict`)

Коллекция пар «ключ — значение». Аналог объекта/хеш-таблицы.

```python
person = {
    "name": "Алиса",
    "age": 25,
    "city": "Москва",
}

# Доступ по ключу
print(person["name"])           # "Алиса"
print(person.get("phone"))      # None — безопасный доступ, не падает с ошибкой
print(person.get("phone", "—")) # значение по умолчанию

# Изменение и добавление
person["age"] = 26               # изменили
person["email"] = "a@b.c"        # добавили новое поле
del person["city"]               # удалили

# Перебор
for key in person:               # по ключам
    print(key, "=", person[key])

for key, value in person.items(): # по парам
    print(key, "=", value)

print(list(person.keys()))       # все ключи
print(list(person.values()))     # все значения
print("name" in person)          # True — проверка наличия ключа
```

### 10.4. Множества (`set`)

Коллекция **уникальных** элементов, **без порядка**.

```python
nums = {1, 2, 3, 3, 2}    # → {1, 2, 3}, дубликаты убираются
nums.add(4)
nums.discard(2)

# Полезно для удаления дубликатов из списка
unique = list(set([1, 1, 2, 2, 3]))   # [1, 2, 3] (порядок может отличаться)

# Операции множеств
a = {1, 2, 3}
b = {3, 4, 5}
print(a | b)   # {1,2,3,4,5} — объединение
print(a & b)   # {3}         — пересечение
print(a - b)   # {1,2}       — разность
print(a ^ b)   # {1,2,4,5}   — симметрическая разность
```

### 10.5. Сравнительная таблица

| Свойство             | list       | tuple    | dict             | set         |
|----------------------|-----------|----------|------------------|-------------|
| Упорядоченность      | да         | да       | да (с 3.7+)      | нет         |
| Изменяемость         | да         | нет      | да               | да          |
| Дубликаты            | да         | да       | ключи — нет      | нет         |
| Доступ по индексу    | да         | да       | по ключу         | нет         |
| Литерал              | `[]`       | `()`     | `{k: v}`         | `{1, 2}`    |

## 11. Функции

Функция — именованный блок кода, который можно вызывать многократно с разными аргументами.

### 11.1. Базовый синтаксис

```python
def greet(name):
    """Выводит приветствие. Это docstring — описание функции."""
    print(f"Привет, {name}!")

greet("Мир")        # Привет, Мир!
greet("Алиса")      # Привет, Алиса!
```

- `def` — ключевое слово, определяет функцию.
- `greet` — имя функции (snake_case).
- `(name)` — список параметров (то, что функция принимает).
- `:` — двоеточие.
- Тело — с отступом.

### 11.2. `return` — возврат значения

```python
def square(x):
    return x * x

result = square(5)    # 25
print(result)
print(square(7))      # 49
```

Функция без `return` (или с `return` без значения) возвращает `None`.

```python
def nothing():
    pass              # pass — заглушка, «ничего не делать»

print(nothing())      # None
```

Функция может возвращать сразу несколько значений (на самом деле — кортеж):

```python
def divmod_(a, b):
    return a // b, a % b

q, r = divmod_(17, 5)
print(q, r)           # 3 2
```

### 11.3. Параметры по умолчанию

```python
def greet(name, greeting="Привет"):
    print(f"{greeting}, {name}!")

greet("Боб")                    # Привет, Боб!
greet("Боб", "Здравствуй")      # Здравствуй, Боб!
greet("Боб", greeting="Йоу")    # Йоу, Боб!  — именованный аргумент
```

Параметры со значением по умолчанию должны идти **после** обычных.

⚠️ Подводный камень: **никогда** не используйте изменяемые объекты (`[]`, `{}`) как значение по умолчанию:

```python
def bad(x, items=[]):       # ПЛОХО: список создаётся ОДИН раз
    items.append(x)
    return items

print(bad(1))   # [1]
print(bad(2))   # [1, 2]   ← неожиданно!

def good(x, items=None):    # правильный паттерн
    if items is None:
        items = []
    items.append(x)
    return items
```

### 11.4. Произвольное число аргументов: `*args`, `**kwargs`

```python
def total(*nums):                # *args собирает все позиционные аргументы в кортеж
    return sum(nums)

print(total(1, 2, 3))            # 6
print(total(1, 2, 3, 4, 5))      # 15

def show(**info):                # **kwargs собирает именованные аргументы в словарь
    for k, v in info.items():
        print(f"{k} = {v}")

show(name="Алиса", age=25)
# name = Алиса
# age = 25
```

### 11.5. Type hints (аннотации типов)

Подсказки типов не влияют на выполнение, но делают код понятнее и помогают IDE/линтерам:

```python
def add(a: int, b: int) -> int:
    return a + b

def greet(name: str = "Мир") -> None:
    print(f"Привет, {name}!")
```

## 12. Области видимости и замыкания

### 12.1. LEGB-правило

Когда Python ищет переменную, он смотрит в области видимости в таком порядке:

1. **L**ocal — внутри текущей функции.
2. **E**nclosing — во вложенных функциях, в объемлющей.
3. **G**lobal — на уровне модуля (файла).
4. **B**uilt-in — встроенные имена (`print`, `len`, …).

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)         # local
    inner()
    print(x)             # enclosing

outer()
print(x)                 # global
```

### 12.2. `global` и `nonlocal`

```python
counter = 0

def increment():
    global counter        # «я хочу менять глобальную переменную, а не создать свою»
    counter += 1

increment()
print(counter)            # 1

def outer():
    x = 10
    def inner():
        nonlocal x        # менять переменную из объемлющей функции
        x += 1
    inner()
    print(x)              # 11

outer()
```

Глобальные переменные — это плохо. Старайтесь передавать данные через параметры и возвращать через `return`.

### 12.3. Замыкания

Функция, «помнящая» переменные из окружающей области:

```python
def make_multiplier(factor):
    def multiplier(x):
        return x * factor    # factor запоминается
    return multiplier

double = make_multiplier(2)
triple = make_multiplier(3)
print(double(5))   # 10
print(triple(5))   # 15
```

## 13. Модули, пакеты и импорты

### 13.1. Что такое модуль

Любой `.py`-файл — это модуль. Чтобы использовать его функции/классы в другом файле, его **импортируют**.

Допустим, есть файл `math_utils.py`:

```python
# math_utils.py
PI = 3.14159

def area_circle(r):
    return PI * r * r
```

И файл `main.py`:

```python
# main.py
import math_utils

print(math_utils.PI)
print(math_utils.area_circle(5))
```

### 13.2. Варианты импорта

```python
import math                       # импорт всего модуля
print(math.sqrt(16))              # 4.0

from math import sqrt, pi         # импорт конкретных имён
print(sqrt(16), pi)

from math import sqrt as s        # с переименованием
print(s(16))

# from math import *              # импорт всего — НЕ ДЕЛАЙТЕ ТАК
```

### 13.3. Стандартная библиотека

## 14. Работа с файлами

### 14.1. Чтение и запись

```python
# Запись (режим 'w' — перезаписывает файл)
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Первая строка\n")
    f.write("Вторая строка\n")

# Чтение целиком
with open("notes.txt", "r", encoding="utf-8") as f:
    text = f.read()
print(text)

# Чтение построчно (экономно по памяти)
with open("notes.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip())   # rstrip убирает '\n' в конце
```

### 14.2. Режимы

| Режим | Что делает                                |
|-------|-------------------------------------------|
| `"r"` | чтение (по умолчанию)                     |
| `"w"` | запись, **перезаписывает** файл           |
| `"a"` | дозапись в конец                          |
| `"x"` | создать новый, ошибка если уже существует |
| `"b"` | бинарный режим (`"rb"`, `"wb"`)           |
| `"t"` | текстовый (по умолчанию)                  |
| `"+"` | чтение и запись (`"r+"`, `"w+"`)          |

### 14.3. Зачем `with`

Конструкция `with` (контекстный менеджер) **гарантированно** закроет файл, даже если внутри произойдёт ошибка. Без `with`:

```python
f = open("file.txt")
data = f.read()
f.close()             # легко забыть, особенно при исключениях
```

С `with` — короче и надёжнее.

### 14.4. JSON

```python
import json

# Записать словарь в файл
data = {"name": "Алиса", "age": 25, "hobbies": ["читать", "бегать"]}
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# Прочитать
with open("data.json", "r", encoding="utf-8") as f:
    data = json.load(f)
print(data["name"])
```

`json.dumps` / `json.loads` — то же самое, но со строкой, а не файлом.

### 14.5. Пути файловой системы — `pathlib`

```python
from pathlib import Path

p = Path("notes.txt")
print(p.exists())          # есть ли файл
print(p.absolute())        # абсолютный путь
print(p.suffix)            # '.txt'
print(p.stem)              # 'notes'
print(p.with_suffix(".md")) # PosixPath('notes.md')

# Создать папку
Path("output").mkdir(exist_ok=True)

# Перебрать все .py файлы в папке
for py_file in Path(".").glob("*.py"):
    print(py_file)
```

`pathlib` — современный путь работы с файлами, лучше чем старый `os.path`.

## 15. Исключения и обработка ошибок

### 15.1. Что такое исключение

Когда возникает ошибка, Python **выбрасывает исключение**. Если его не «поймать» — программа аварийно завершится.

```python
print(10 / 0)        # ZeroDivisionError
int("abc")           # ValueError
my_list[100]         # IndexError
my_dict["nope"]      # KeyError
open("missing")      # FileNotFoundError
```

### 15.2. `try / except`

```python
try:
    n = int(input("Введите число: "))
    print(10 / n)
except ZeroDivisionError:
    print("На ноль делить нельзя")
except ValueError:
    print("Это не число")
except Exception as e:
    print(f"Какая-то другая ошибка: {e}")
else:
    print("Всё прошло без ошибок")    # выполнится, если try НЕ упал
finally:
    print("Этот блок выполнится всегда")
```

Правила:

- Обрабатывайте **конкретные** исключения, а не «всё подряд». `except Exception` — крайний случай.
- Никогда не делайте «голый» `except:` — он перехватит даже `KeyboardInterrupt` и системные ошибки.
- В `as e` переменная `e` хранит сам объект исключения — оттуда можно достать сообщение.

### 15.3. Бросить своё исключение

```python
def withdraw(amount):
    if amount <= 0:
        raise ValueError("Сумма должна быть положительной")
    ...
```

### 15.4. Свои классы исключений

```python
class InsufficientFundsError(Exception):
    """Не хватает денег на счету"""

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFundsError(f"Не хватает {amount - balance}")
    return balance - amount
```

Когда использовать исключения, а когда — `if`? Принцип: исключения — для **исключительных** ситуаций (то, что *не должно* происходить в норме). Обычная валидация — через `if`.

## 16. ООП: классы и объекты

ООП (объектно-ориентированное программирование) — способ структурировать код вокруг «объектов» с состоянием и поведением.

### 16.1. Класс и экземпляр

```python
class Dog:
    """Класс, описывающий собаку."""

    def __init__(self, name, age):     # конструктор
        self.name = name                # атрибут объекта
        self.age = age

    def bark(self):                     # метод
        print(f"{self.name} говорит: Гав!")

# Создание экземпляров (объектов)
rex = Dog("Рекс", 3)
buddy = Dog("Бадди", 5)

print(rex.name)    # Рекс
rex.bark()         # Рекс говорит: Гав!
buddy.bark()       # Бадди говорит: Гав!
```

Разбор:

- `class Dog:` — определение класса. По соглашению — **PascalCase**.
- `def __init__(self, ...)` — **конструктор**, вызывается при создании объекта.
- `self` — ссылка на сам объект. **Всегда** первый параметр методов.
- `self.name = name` — создаём атрибут объекта.

### 16.2. Атрибуты класса vs объекта

```python
class Dog:
    species = "Canis lupus familiaris"   # атрибут класса — общий для всех

    def __init__(self, name):
        self.name = name                  # атрибут объекта — свой у каждого

print(Dog.species)        # обращаемся через имя класса
rex = Dog("Рекс")
print(rex.species)        # тоже доступен через объект
print(rex.name)
```

## 17. Наследование, полиморфизм, инкапсуляция

### 17.1. Наследование

Один класс может «наследовать» другой — получить все его атрибуты и методы.

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} издаёт звук")

class Dog(Animal):                # Dog наследует Animal
    def speak(self):              # переопределяем метод
        print(f"{self.name}: Гав!")

class Cat(Animal):
    def speak(self):
        print(f"{self.name}: Мяу!")

animals = [Dog("Рекс"), Cat("Барсик"), Animal("Существо")]
for a in animals:
    a.speak()
```

`super()` — вызвать метод родительского класса:

```python
class Puppy(Dog):
    def __init__(self, name, owner):
        super().__init__(name)         # вызываем Dog.__init__
        self.owner = owner
```

### 17.2. Полиморфизм

Разные классы реализуют один интерфейс по-своему. В примере выше `speak()` есть у каждого, но делает разное — это и есть полиморфизм. Код, который вызывает `a.speak()`, не знает, какой именно класс перед ним.

### 17.3. Инкапсуляция

В Python нет настоящих `private`-полей, но есть соглашения:

- `name` — публичное (используйте свободно);
- `_name` — «приватное по соглашению» (трогать снаружи не стоит, но технически можно);
- `__name` — name-mangling: атрибут получит имя `_ClassName__name`, его тяжелее «случайно» использовать снаружи.

```python
class Account:
    def __init__(self, balance):
        self._balance = balance        # внутренний атрибут

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Сумма должна быть > 0")
        self._balance += amount

    def get_balance(self):
        return self._balance
```

### 17.4. `@property`

Делает метод похожим на атрибут — удобно для геттеров/сеттеров:

```python
class Person:
    def __init__(self, first, last):
        self.first = first
        self.last = last

    @property
    def full_name(self):
        return f"{self.first} {self.last}"

p = Person("Иван", "Петров")
print(p.full_name)   # "Иван Петров" — обращаемся как к атрибуту, без скобок
```

### 17.5. `@classmethod` и `@staticmethod`

```python
class Date:
    def __init__(self, day, month, year):
        self.day, self.month, self.year = day, month, year

    @classmethod
    def from_string(cls, s):                 # альтернативный конструктор
        d, m, y = map(int, s.split("."))
        return cls(d, m, y)

    @staticmethod
    def is_leap(year):                       # независимая утилита, без self
        return year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)

d = Date.from_string("01.01.2024")
print(Date.is_leap(2024))   # True
```

## 18. Магические методы (dunder-методы)

Это методы с двойными подчёркиваниями (`__init__`, `__str__`, …), которые Python вызывает в особых случаях.

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __repr__(self):                   # для отладки: print(repr(v))
        return f"Vector({self.x}, {self.y})"

    def __str__(self):                    # для пользователя: print(v)
        return f"({self.x}; {self.y})"

    def __add__(self, other):             # перегрузка оператора +
        return Vector(self.x + other.x, self.y + other.y)

    def __eq__(self, other):              # перегрузка ==
        return self.x == other.x and self.y == other.y

    def __len__(self):                    # позволяет использовать len()
        return int((self.x**2 + self.y**2) ** 0.5)

a = Vector(1, 2)
b = Vector(3, 4)
print(a + b)            # (4; 6)
print(a == Vector(1,2)) # True
print(len(b))           # 5
```

Полезные dunder-методы:

- `__init__` — конструктор;
- `__repr__`, `__str__` — текстовое представление;
- `__len__`, `__getitem__`, `__setitem__` — поддержка `len()`, `obj[i]`;
- `__iter__`, `__next__` — итерация;
- `__add__`, `__sub__`, `__mul__`, `__eq__`, `__lt__` — операторы;
- `__enter__`, `__exit__` — контекстный менеджер (для `with`);
- `__call__` — объект можно «вызывать» как функцию.

## 19. Итераторы и генераторы

### 19.1. Итератор

Объект, по которому можно итерироваться. Должен поддерживать методы `__iter__` (вернуть итератор) и `__next__` (вернуть следующий элемент или поднять `StopIteration`).

```python
nums = [1, 2, 3]
it = iter(nums)
print(next(it))   # 1
print(next(it))   # 2
print(next(it))   # 3
# next(it)        # StopIteration
```

`for x in xs:` — это и есть цикл по итератору.

### 19.2. Генераторы

Самый удобный способ создавать итераторы — функция-генератор с `yield`:

```python
def count_up_to(n):
    i = 1
    while i <= n:
        yield i        # «отдать» значение и приостановить функцию
        i += 1

for x in count_up_to(5):
    print(x)            # 1, 2, 3, 4, 5
```

Преимущества генераторов:

- ленивые — значения вычисляются по требованию;
- экономят память (не хранят все значения сразу);
- удобны для бесконечных последовательностей.

```python
def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

import itertools
print(list(itertools.islice(fibonacci(), 10)))  # первые 10 чисел Фибоначчи
```

Генераторное выражение (как list comprehension, но с круглыми скобками):

```python
squares = (x*x for x in range(10**6))   # не создаёт миллион чисел сразу
print(sum(squares))
```

## 20. Декораторы

Декоратор — функция, которая **оборачивает** другую функцию, добавляя ей поведение, не меняя её код.

### 20.1. Простой пример

```python
def log_calls(func):
    def wrapper(*args, **kwargs):
        print(f"Вызов {func.__name__} с {args} {kwargs}")
        result = func(*args, **kwargs)
        print(f"  → результат: {result}")
        return result
    return wrapper

@log_calls
def add(a, b):
    return a + b

add(2, 3)
# Вызов add с (2, 3) {}
#   → результат: 5
```

`@log_calls` над определением функции эквивалентно `add = log_calls(add)`.

### 20.2. Декоратор с аргументами

```python
def repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(n):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def hello():
    print("Hi")

hello()    # Hi напечатается 3 раза
```

### 20.3. Сохранение метаданных

После оборачивания у функции теряются `__name__`, `__doc__`. Чтобы сохранить — `functools.wraps`:

```python
from functools import wraps

def log_calls(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        ...
    return wrapper
```

Декораторы — основа многих фреймворков (Flask, FastAPI, pytest).

## 21. Lambda, map, filter, reduce, comprehensions

### 21.1. Lambda — анонимные функции

```python
square = lambda x: x * x
print(square(5))    # 25

# Эквивалент:
def square(x):
    return x * x
```

Lambda — это **выражение**, поэтому в ней может быть только одно выражение, без `return`. Используйте только для очень коротких функций.

### 21.2. `map`, `filter`, `reduce`

```python
nums = [1, 2, 3, 4, 5]

# map: применить функцию к каждому элементу
squares = list(map(lambda x: x*x, nums))           # [1, 4, 9, 16, 25]

# filter: оставить только те, что прошли условие
evens = list(filter(lambda x: x % 2 == 0, nums))   # [2, 4]

# reduce: «свернуть» в одно значение
from functools import reduce
total = reduce(lambda acc, x: acc + x, nums, 0)    # 15
```

### 21.3. Comprehensions — pythonic-аналоги

В Python всё это обычно пишут через списочные включения (list comprehension), это короче и читаемее:

```python
nums = [1, 2, 3, 4, 5]

squares = [x*x for x in nums]                  # вместо map
evens = [x for x in nums if x % 2 == 0]        # вместо filter
sq_evens = [x*x for x in nums if x % 2 == 0]   # совмещаем

# Словарное включение
sq_dict = {x: x*x for x in nums}               # {1:1, 2:4, ...}

# Множественное включение
unique_squares = {x*x for x in [-2, -1, 1, 2]} # {1, 4}

# Генераторное выражение (ленивое, экономит память)
gen = (x*x for x in range(10**6))
```

Двумерное включение:

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flat = [n for row in matrix for n in row]       # [1,2,3,4,5,6,7,8,9]
```

## 24. Стиль кода (PEP 8) и хорошие практики

[PEP 8](https://peps.python.org/pep-0008/) — официальный стиль Python. Основные правила:

- **Отступ**: 4 пробела, без табов.
- **Длина строки**: ≤ 79 символов (или 100, если так принято в проекте).
- **Имена**:
  - переменные и функции — `snake_case`;
  - классы — `PascalCase`;
  - константы — `UPPER_SNAKE_CASE`;
  - «приватное» — с подчёркивания: `_helper`.
- **Пробелы**: вокруг `=` (`a = 1`), но **не** вокруг `=` в аргументах по умолчанию (`f(a=1)`); после запятой и `:`.
- **Импорты**: каждый с новой строки, в порядке: стандартная библиотека → сторонние → свои; разделены пустой строкой.
- **Docstring** для модулей/классов/функций (PEP 257).
- **Не сравнивайте с None через `==`** — пишите `x is None`.

Инструменты:

- **`ruff`** — быстрый линтер и форматтер, заменяет flake8/black/isort.
- **`black`** — авто-форматтер, не спорит со стилем.
- **`mypy`** или **`pyright`** — статическая проверка типов.

## Приложение A: типичные ошибки новичка

1. **`IndentationError`** — перепутали отступы. Используйте 4 пробела всегда.
2. **`NameError: name 'x' is not defined`** — переменная не объявлена или опечатка в имени.
3. **`TypeError: can only concatenate str (not "int") to str`** — пытаетесь `"a" + 1`. Преобразуйте: `"a" + str(1)`.
4. **`SyntaxError: invalid syntax`** — пропущены `:`, скобки, кавычки.
5. **`KeyError`** — обращение к несуществующему ключу словаря. Используйте `dict.get(key)`.
6. **`IndexError`** — выход за границы списка.
7. **`ValueError: invalid literal for int()`** — `int("abc")`. Проверяйте ввод.
8. **Бесконечный цикл `while`** — забыли изменять переменную внутри.
9. **Неожиданное изменение списка** — передаёте список в функцию и меняете его. Списки передаются «по ссылке».
10. **`UnboundLocalError`** — присваиваете глобальной переменной внутри функции без `global`.
